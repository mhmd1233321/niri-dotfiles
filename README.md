# 🌧️ Niri Auto-Lyric & Music Vis Rice

High-performance terminal-based music visualization setup on Arch Linux & Niri WM.

## 🛠️ Stack
* **OS:** Arch Linux
* **WM:** Niri (Wayland)
* **Terminal:** Kitty + Fish Shell
* **Player:** Amberol
* **Visualization:** `lrc-vis` + `cava` + `lrc-tools`

## 🚀 Quick Setup
Copy `config/*` to `~/.config/`
